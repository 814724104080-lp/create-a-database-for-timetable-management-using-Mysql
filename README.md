README – Time Table Management System

Project Title

Time Table Management System using DBMS


---

Introduction

The Time Table Management System is a database project developed using SQL in DBMS. The system is designed to manage and organize timetable schedules for educational institutions such as schools and colleges.

It stores details about departments, teachers, students, subjects, classrooms, and timetable schedules in a structured manner.


---

Objectives

To automate timetable management

To reduce manual scheduling errors

To maintain teacher and classroom allocation

To store and retrieve timetable information efficiently



---

Software Requirements

MySQL / Oracle / SQL Server

DBMS Environment

SQL Query Editor



---

Database Tables Used

1. Department


2. Teacher


3. Student


4. Subject


5. Classroom


6. Timetable




---

Features

Add departments and subjects

Store teacher and student details

Allocate classrooms

Create timetable schedules

Display timetable information using SQL queries



---

INSERT

SELECT

---

Sample Output

The system displays:

Day of class

Period number

Subject name

Teacher name

Classroom details



---

Advantages

Easy timetable management

Reduces paperwork

Avoids scheduling conflicts

Fast retrieval of records

Improves academic management



---

Conclusion

The Time Table Management System is an efficient DBMS project that helps institutions manage academic schedules effectively. It simplifies timetable creation and improves data organization using SQL databases.
